= tung

tung is a small functional programming tongue with

* type inference, algebraic data,
* closed records,
* type classes,
* algebraic effects,
* and infix notation.

== install

install the command and vscode extension.

[source,sh]
----
brew bundle
make install
----

the command is installed at `~/.local/bin/tung` by default.
set `PREFIX` or `BIN_DIR` to choose another destination.

== run

[cols="1,1",options="header"]
|===
| command
| purpose

| `tung program.tung [arguments...]`
| runneth `main` with the remaining arguments

| `tung --check program.tung`
| checketh a program with `main`

| `tung --check-module module.tung`
| checketh a program without `main`

| `tung --type-of name program.tung`
| printeth the inferred type of a name

| `tung --format file.tung [more.tung...]`
| formateth files in stead

| `tung --repl`
| starteth the interactive checker and evaluator
|===

`main` taketh `𝟙`, yieldeth `𝟙`, and may use the standard runtime effects.

[source,tung]
----
bring ground.tung

let (_: 𝟙) main: 𝟙 ! console =
  'hello, tung' write-line
----

examples are in link:byspel/[`byspel/`].

== syntax

tung useth function-second syntax for application.
`$` groupeth the expression on its left before passing it to the function on its right.

[source,tung]
----
a f          # f a in haskell
a f b c      # f a b c in haskell
a f $ g b    # g (f a) b in haskell
----

functions are curried.
effects follow `!` on a function arrow, and
`(term: type)` constraineth any term.

closed records use `[field = value]`;
`[= record, field = value]` updateth a record, and `[= record, - field]` removeth a field.

== keywords

[cols="1,6",options="header"]
|===
| keyword
| use

| `let`
| bindeth a value to a name

| `graith`
| requireth shape evidence from the caller

| `show`
| publisheth a declaration or re-publisheth a visible term

| `show-ilk`
| publisheth a type, effect, or shape name

| `bring`
| importeth a module

| `let-ilk`
| defineth a type alias

| `kin`
| declareth an algebraic data type and its constructors

| `deed`
| declareth an algebraic effect and its operations

| `yield`
| return a block result or handleth a normal `try` result

| `fremmed`
| bindeth an annotated file-level `let` to the host function named by a text key

| `shape`
| declareth a statically selected interface, defaults, and laws

| `fill`
| provideth evidence and implementations for a shape

| `law`
| recordeth a type-checked equation without proving it

| `match`
| selecteth an exhaustive, non-redundant pattern case

| `try`
| handleth effects performed by an expression

| `eftgin`
| continueth the captured computation inside an operation case
|===

`bring` introduceth a module with the file name or an optional name given.

[source,tung]
----
bring data/list.tung
bring data/table.tung hashmap

let my-empty-list = list@empty
let my-empty-table = hashmap@empty
----

imported names may stay bare when unambiguous.
declarations remain private unless published with `show` or `show-ilk`. module lookup searcheth local files,
`TUNG_PATH`, then the embedded standard bookhoard.

handlers are deep, and thou mayst call `eftgin` more than once.
partial application is pure; an effect operation runneth only when fully applied.

[source,tung]
----
bring ground.tung

deed ask {
  integer ask: integer
}

let answer: text = try 10 ask {
  yield n | n to-text,
  n ask | (n + 1) eftgin
}
----

evaluation is strict and call-by-value.
checking precedeth evaluation, and file-level initialisation must stay pure.

=== editor and reference

the vscode extension provideth highlighting, diagnostics, navigation, formatting, and a run button; xref:vscode/readme.adoc[`vscode/readme.adoc`] covereth its
commands and settings.

the generated standard-library reference is written to `writ/bookhoard/index.html` by `make docs`. xref:tongue/agent.adoc[`tongue/agent.adoc`] is the complete language reference.

== develope

compiler development requireth GHC 9.12 or newer; CI useth GHC 9.12.4. install the git hooks once.

[source,sh]
----
lefthook install
----

[cols="1,3"]
|===
| `make setup`
| test, generate documentation, and install the command and extension
| `make build`
| build the compiler, extension, and documentation generator
| `make test`
| run every test suite
| `make compiler-test`
| run compiler, evaluator, library, and integration tests
| `make benchmark`
| run repeatable compiler and evaluator benchmarks
| `make docs`
| generate the searchable bookhoard reference
|===
