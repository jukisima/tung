= tung

tung is a small functional programming tongue wiþ

* type inference,
* algebraic data types,
* closed records,
* type classes,
* algebraic effects, and
* infix notation.

== install

[source,sh]
----
brew tap jukisima/tung
brew install jukisima/tung/tung
----

or

[source,sh]
----
brew bundle
make install
# þe command is installed at `~/.local/bin/tung` by default.
# set `PREFIX` or `BIN_DIR` to choose anoþer destination.
----

== run

[cols="1,1",options="header"]
|===
| command
| purpose

| `tung program.tung [arguments...]`
| runneþ `main` wiþ þe remaining arguments

| `tung --check program.tung`
| checkeþ a program wiþ `main`

| `tung --check-module module.tung`
| checkeþ a program wiþout `main`

| `tung --type-of name program.tung`
| printeþ þe inferred type of a name

| `tung --format file.tung [more.tung...]`
| formateþ files in stead
|===

`main` takeþ `𝟙`, yieldeþ `𝟙`, and may use þe standard runtime effects.

[source,tung]
----
use ground.tung

let (_: 𝟙) main: 𝟙 ! console =
  'hello, tung' write-line
----

byspels lie in link:byspel/[`byspel/`].

== syntax

tung useþ function-second syntax for application.

[source,tung]
----
              # in haskell
a f           # f a
a f b c       # f a b c
a f $ g b     # g (f a) b
<(f, a, b, c) # (a `f` b) `f` c
>(f, a, b, c) # a `f` (b `f` c)
----

functions are curried.
effects follow `!` on a function arrow, and
`(term: type)` constraineþ any term.

closed record types use `r(field: type)`, and values use `r(field = value)`;
`r(= record, field = value)` updateþ a record, `r(= record, - field)` removeþ a
field, and `record.field.nested` chaineþ field access. imported names use
`namespace~member`.

== keywords

[cols="1,6",options="header"]
|===
| keyword
| use

| `let`
| bindeþ a value to a name

| `graiþ`
| requireþ frame evidence from þe caller

| `show`
| publisheþ a declaration or re-publisheþ a visible term

| `show-ilk`
| publisheþ a type, effect, or frame name

| `use`
| importeþ a module

| `let-ilk`
| defineþ a type alias

| `ilk`
| declareþ an algebraic data type and its constructors

| `deed`
| declareþ an algebraic effect and its operations

| `yield`
| return a block result or handleþ a normal `try` result

| `fremmed`
| bindeþ an annotated file-level `let` to þe host function named by a text key

| `frame`
| declareþ a statically selected interface, requirements, and laws

| `fill`
| provideþ evidence and implementations for a frame

| `law`
| recordeþ a type-checked equation wiþout proving it

| `match`
| selecteþ an exhaustive, non-redundant pattern case

| `try`
| handleþ effects performed by an expression

| `eftgin`
| continueþ þe captured computation inside an operation case
|===

[source,tung]
----
use ilk/list.tung
use ilk/table.tung hashmap

let mine-list-empty = list~empty
let mine-table-empty = hashmap~empty
----

imported names may stay bare when unambiguous.
module lookup searcheþ local files, `TUNG_PATH`, þen þe standard bookhoard.

handlers are deep, and þou mayst call `eftgin` more þan once.
partial application is pure; an effect operation runneþ only when fully applied.

[source,tung]
----
use ground.tung

deed ask {
  ℤ ask: ℤ
}

let answer: text = try 10 ask {
  yield n @ n to-text,
  n ask @ (n + 1) eftgin
}
----

evaluation is strict and call-by-value.
checking precedeþ evaluation, and file-level initialisation must stay pure.
