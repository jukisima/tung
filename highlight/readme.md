# jbini tongue support

vscode syntax highlighting for `.jbini` files.

## local use

open this `highlight` folder in vscode and press `f5` to start an extension development host.

the extension contributes:

- language id `jbini`
- file extension `.jbini`
- root textmate scope `source.jbini`
- line comments with `#`
- bracket and quote pairs for jbini source
